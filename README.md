## About

This is a single-page application built with vanilla HTML, CSS, and JavaScript. It showcases copywriting work, services, process, and a contact section — all navigated client-side without any page reloads.

---

## Pages

| Page | Description |
|------|-------------|
| **Home** | Hero section, services overview, featured work, and testimonials |
| **Work** | Portfolio of copywriting projects across categories |
| **Services** | Detailed breakdown of offerings and pricing |
| **About** | Background, values, tools, work process, and fun facts |
| **Tips & Tricks** | Free copywriting insights and resources |
| **Contact** | Hire form and direct contact links |

## Tech Stack

- **HTML5** — semantic markup, single `index.html` file
- **CSS3** — custom properties, grid, flexbox, animations
- **Vanilla JavaScript** — page routing, scroll effects, cursor, interactions
- **Google Fonts** — Playfair Display, DM Sans, Cormorant Garamond

No frameworks. No dependencies. No build step.

## Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/hundredes-portfolio.git
   cd hundredes-portfolio
   ```

2. Open with Live Server (VS Code) or any local server:
   ```bash
   # With VS Code — install the Live Server extension, then click "Go Live"
   # Or with Python:
   python -m http.server 5501
   ```

3. Visit `http://localhost:5501` in your browser.

> **Note:** Opening `index.html` directly as a `file://` URL works too, but a local server is recommended for consistent font loading.
